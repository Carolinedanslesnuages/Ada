# Logo d'ADA

| Fichier | Usage |
|---|---|
| `ada-logo.svg` | Le mot « ada » : en-tête de l'interface (logo d'opérateur du DSFR), documents |
| `ada-logo-complet.svg` | « ada » et « Atelier de Développement Assisté » : README, présentations |
| `ada-icone.svg` | Icône carrée : onglet du navigateur (`interface/front/public/favicon.svg`) |

- Couleurs du DSFR : bleu France `#000091`, rouge `#E1000F` (l'étincelle : « Assisté »).
- Lettres dessinées (cercles et traits), sans police : le logo s'affiche partout pareil. Seul le
  sous-titre de `ada-logo-complet.svg` est du texte (Marianne, sinon Arial).
- Pas de Marianne ni de bloc-marque « République française » dans le logo : ils sont réservés à
  l'identité officielle de l'État (l'en-tête du DSFR les affiche à côté).
